# mushroom-foraging

A plain HTML/CSS/JS site. No build step, no dependencies.

## Run

Just open `index.html` in a browser, or serve it (handy for correct paths and
live-ish reload):

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Files

- `index.html` — markup
- `styles.css` — styles (light/dark aware)
- `main.js` — behavior
